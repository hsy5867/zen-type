🎯 三模式快捷鍵

預設 Pause 鍵，也可改用 F-鍵（如 F5/F8/F9…），都不會跟系統快捷鍵或中文輸入法衝突。

⚠ 避免以下組合：
• Alt+Space — Windows 視窗系統選單會優先處理（在記事本等會失效）
• Ctrl+Space / Ctrl+Shift / Ctrl+Shift+Space — 中文輸入法切換
• Alt+字母 — 應用程式功能表捷徑
• Win+任何鍵 — Windows 系統保留
